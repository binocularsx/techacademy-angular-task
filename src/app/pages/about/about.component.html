About Posh

This page proves the app has more than one route: the navbar links here using routerLink, and this view renders through the shell's <router-outlet>.

Posh started life as a static HTML template. This assessment rebuilds it as a proper Angular application: each section of the original page is now its own standalone component, data flows down through Signal-based input()s, and user actions flow back up through output() events — instead of one giant page of copy-pasted markup.
